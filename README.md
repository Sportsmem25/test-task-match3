# Prototype match3
Данный проект выполнен согласно тестовому заданию на позицию "Junior/Middle Unity C# разработчик" с упором на:
- чистую архитектуру,
- объектно-ориентированное программирование,
- использование возможностей Unity,
- интеграцию UI через DoozyUI.

## Описание тестового задания
Реализовать проект в жанре Match3 - у игрока есть игровое поле n x m элементов. На старте, поле заполняется кристаллами разного цвета. Игрок меняет кристаллы местами, чтобы соединить элементы, совпадающие по цвету. 
Элементы уничтожаются при соединении трёх и более штук, после уничтожения, поле заполняется сверху - верхние кристаллы падают на место уничтоженных, а в самом верху генерируются новые кристаллы. 

## Описание проекта
Игра представляет собой классическую механику Match-3:
- Игровое поле размером "NxM";
- Поле заполняется гемами случайных типов;
- Игрок может менять местами соседние гемы;
- При совпадении 3 и более гемов начисляются очки, гемы уничтожаются, оставшиеся гемы падают вниз, сверху спавнятся новые гемы;
- Поддерживаются цепочки матчей (комбо).

Проект разделён на логические подсистемы - Core (управление игровой логикой), Systems (подсчет очков, управление состоянием игры), UI (управление HUD, отображение комбо-попапов). 
В проекте использованы следующие паттерны проектрирования: Singleton, Factory Pattern, а также корутины. Кроме того в проекте используется DoozyUI для управлением UI и анимации элементов UI.
